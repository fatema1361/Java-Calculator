# 🧮 Java Calculator

A simple calculator application built using **Java Swing**. This project provides a graphical user interface (GUI) to perform basic arithmetic operations.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 Percentage calculation
* ➕/➖ Positive and negative number conversion
* 🔘 Decimal number support
* 🧹 Clear all (`AC`) button
* 🎨 User-friendly interface with colored buttons
* ⚠️ Division-by-zero error handling

## 🛠️ Technologies Used

* **Java** — Programming language
* **Java Swing** — GUI components
* **AWT** — Layouts, colors, fonts, and event handling

## 📋 Requirements

* Java Development Kit (JDK) installed
* Any Java-compatible IDE, such as IntelliJ IDEA,  VS Code
